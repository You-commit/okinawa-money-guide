## 2. 追加する全体工程

### Phase 5追補：検索流入・インデックス強化

目的：ホームだけでなく、各シミュレーター、知識ページ、今後追加する記事が検索エンジンから個別に発見・評価・流入される状態を作る。

#### P5-ADD-SEO-01 インデックス状態の実測

- Google Search Consoleでプロパティ、サイトマップ、URL検査結果を確認する。
- 対象は最低限以下とする。
  - `/simulators/military-land`
  - `/simulators/mortgage`
  - `/simulators/nisa`
  - `/simulators/ideco`
  - `/simulators/taxable-income`
  - `/knowledge`
  - 今後の詳細記事
- 「クロール可能」と「Googleにインデックス済み」を分けて記録する。
- Search Console接続前は公開検索結果を補助証拠として扱い、インデックス有無の正本とはしない。

**完了条件**：主要URLごとに、インデックス状況・検出経路・問題有無が確認できること。

#### P5-ADD-SEO-02 シミュレーターの検索評価強化

既存のroute別title、description、canonical、robots、静的HTML、sitemapを維持したうえで、検索エンジンが各シミュレーターを独立した有用ページとして理解できるよう強化する。

- 各ページに検索意図に合う可視本文を追加する。
- 「何が計算できるか」「どんな判断に使えるか」「前提・注意点」「関連制度」「次に確認すること」を明確化する。
- 計算機そのものより前に過剰なSEO文章を置かず、利用体験を優先する。
- 主要シミュレーターへ内部リンクを増やす。
- パンくず導線を整備する。
- 必要に応じて `BreadcrumbList`、`WebPage` 等の事実に基づく構造化データを追加する。
- 実際の更新日に限ってsitemapの `lastmod` を管理する。架空の日付は設定しない。

**完了条件**：各シミュレーターに固有の検索意図・可視本文・内部リンク・適切なメタ情報があり、初期HTTP HTMLと実画面の内容が矛盾しないこと。

#### P5-ADD-SEO-03 インデックス促進

- `sitemap.xml` に全index対象ページを含める。
- 新規記事公開時にサイトマップを更新する。
- Search Consoleでサイトマップ送信と重要URLのURL検査を実施する。
- クロールエラー、重複、canonical不一致、soft 404を継続監視する。

**完了条件**：主要シミュレーターと主要記事がGoogle側で検出され、インデックス可否を追跡できること。

#### P5-ADD-SEO-04 検索パフォーマンス運用

- URL別の表示回数、クリック、CTR、平均掲載順位を確認する。
- クエリ別に、シミュレーターと記事の役割を分ける。
- タイトル・descriptionはCTRだけを目的に煽らず、ページ内容と一致させる。
- 検索順位だけでなく、シミュレーター利用、記事→シミュレーター遷移も見る。

**完了条件**：月次で検索流入と改善候補を判断できること。

### Phase 7追補：記事・コンテンツ強化

目的：`/knowledge` を単なる案内ページから、沖縄固有の金融課題を深く解決するコンテンツハブへ発展させる。

#### P7-ADD-CONTENT-01 記事情報設計

- 「借りる」「貯める」「増やす」「備える」の既存4カテゴリを維持する。
- 沖縄固有テーマを横断タグとして扱う。
- 詳細記事は1記事1検索意図を原則とする。
- 記事から関連シミュレーターへ自然に遷移できるようにする。
- 収益案件がなくても必要な記事は作る。

#### P7-ADD-CONTENT-02 優先記事クラスター

初期優先テーマは以下とする。

1. 沖縄の住宅ローン
   - 沖縄銀行・琉球銀行・沖縄海邦銀行等の比較時の確認項目
   - 金利だけでなく保証料、手数料、団信、返済方法、借換えを扱う
   - 住宅ローンシミュレーターへ接続
2. 沖縄県民向けNISA
   - 制度、投資枠、リスク、証券口座選択時の確認項目
   - NISAシミュレーターへ接続
3. iDeCo
   - 加入区分、掛金上限、税効果、制度改正日
   - iDeCoシミュレーターへ接続
4. 軍用地
   - 倍率、借地料、表面利回り、費用、共有持分、回収期間
   - 軍用地シミュレーターへ接続
5. 沖縄の自動車保険
   - 保険料だけでなく補償、車利用、台風・自然災害等の確認点
6. 沖縄の火災・住宅保険
   - 台風・風災等を含む補償確認
7. 沖縄の家計・生活コスト
   - 車、住居、保険、教育、地域差を事実ベースで整理
8. 所得税・住民税
   - 全国制度と那覇市等の地域差を混同しない
   - 課税所得シミュレーターへ接続

#### P7-ADD-CONTENT-03 記事品質基準

- 金融機関、公的機関、法令、制度運営主体等の一次情報を優先する。
- 金利、手数料、商品条件は基準日を表示する。
- 更新日だけを新しく見せる行為をしない。
- 事実、試算、編集上の解説を区別する。
- 出典を記事内または記事末に明示する。
- 実在しない体験談、利用者評価、受賞歴、専門家コメントを作らない。
- AI生成量産を目的にせず、検索意図を解決できる深さを優先する。
- 広告案件があることを理由に記事結論を変えない。

#### P7-ADD-CONTENT-04 記事とシミュレーターの接続

基本導線：

`検索 → 記事 → 判断材料 → シミュレーター → 必要なユーザーのみ関連サービス`

記事中の広告を主役にせず、シミュレーターと一次情報への導線を優先する。

## 4. 最重要原則

優先順位は常に以下とする。

**信頼性・ユーザー価値 → 沖縄特化という独自性 → 収益化**

検索順位や広告収益を理由に、金融情報の正確性、比較の中立性、シミュレーターの説明可能性を低下させない。
